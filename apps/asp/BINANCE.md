# Binance Live Feed — Real, Reachable, Load-Bearing

Verified on this VM: `api.binance.com` responds to unauthenticated public market-data calls.

```
GET https://api.binance.com/api/v3/ticker/price?symbol=BTCUSDT
→ {"symbol":"BTCUSDT","price":"77292.00000000"}
```

The Binance feed is the **paid resource** the x402 paywall unlocks. It is not the product
by itself — the product is granting *per-call, subscription-free, key-free* access to it via
Binance Agent OS x402, with spend-limits and on-chain receipts. Remove x402 and the gate that
prices every request disappears; the product stops being pay-per-call.
